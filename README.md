# 📊 Unemployment Analysis with Python
## CodeAlpha Data Science Internship — Task 2

## 📌 Overview
An exploratory data analysis of unemployment trends in India (2019-2020) using Python, investigating the impact of Covid-19 on unemployment rates across different regions and areas.

## 🛠️ Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📓 Notebook Structure
1. **Data Overview** — Loading datasets, understanding shape, columns and basic statistics
2. **Data Cleaning** — Handling missing values, fixing data types, stripping whitespace
3. **Unemployment Trend Over Time** — Line chart showing monthly unemployment rate (2019-2020)
4. **Region-wise Unemployment** — Bar chart comparing average unemployment across Indian states
5. **Urban vs Rural Unemployment** — Bar chart comparing unemployment between Urban and Rural areas
6. **Covid-19 Impact Analysis** — Bar chart comparing Pre-COVID vs COVID period unemployment rates
7. **Correlation Heatmap** — Heatmap showing relationships between unemployment, employment and labour participation
8. **Key Insights & Conclusions** — Summary of findings and policy implications

## 🔍 Key Insights
- Unemployment spiked significantly during Covid-19 lockdowns in 2020
- Urban areas have higher unemployment rates than Rural areas
- Tripura and Haryana have the highest average unemployment rates
- Unemployment jumped from ~8% pre-COVID to ~20%+ during COVID period
- Labour Participation Rate shows negative correlation with Unemployment Rate

## 📁 Dataset
- `Unemployment in India.csv` — Monthly unemployment data by region (2019-2020)
- `Unemployment_Rate_upto_11_2020.csv` — Unemployment data with geographic coordinates
